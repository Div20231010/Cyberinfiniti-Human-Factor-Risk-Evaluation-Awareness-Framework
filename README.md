# **Cyberinfiniti-Human-Attack-Surface-Reduction-Accessibility-Framework**

This project demonstrates a comprehensive human‑factor risk evaluation and a tailored security awareness framework for **Cyberinfiniti Ltd**, integrating accessibility testing, behavioral vulnerability analysis, and customized training design to reduce exposure to human error and social engineering threats.  

A team of eight security analysts worked together to assess human-related cybersecurity threats and design a practical, accessible security awareness program for a simulated organization, Cyberinfiniti Ltd.

## **About the Organization**
Cyberinfiniti Ltd is a specialized cybersecurity provider operating as a **Managed Security Service Provider (MSSP)**. Its portfolio includes:  
- 24/7 Security Operations Center (SOC) management  
- Advanced threat detection and monitoring  
- Vulnerability assessment and penetration testing  
- Cloud security advisory services  
- Governance, Risk, and Compliance (GRC) consulting  
- Security awareness and professional training  

Because of the sensitive nature of its operations, Cyberinfiniti manages:  
- Client infrastructure configurations  
- Threat intelligence feeds  
- Vulnerability reports  
- Compliance documentation  
- Personal data under NDPA scope  

➡️ This makes **human behavior one of the most critical risk factors** in cybersecurity resilience.

---

## **Project Objective**
The project aimed to:  
- Identify human‑centric cybersecurity vulnerabilities  
- Analyze real‑world incidents caused by human error  
- Develop a structured and adaptive awareness framework  
- Integrate accessibility and inclusivity into training delivery  
- Evaluate usability of the Vivida Reels learning platform  

---

## **Human Factor Threat Assessment**
We identified key risks relevant to MSSP operations:  
- 📧 Phishing & Social Engineering  
- 🔑 Credential Mismanagement  
- 🕵️ Insider Threats  
- ⚙️ Misconfigured Security Tools  
- 📶 Public WiFi Risks  
- 🤝 Third‑Party Vendor Exposures  

📊 *Human Risk Matrix* was developed to evaluate each threat by likelihood and impact.

## **Security Awareness Program Design**
A tailored awareness program was built using the **Vivida platform**.  

### Core Training Modules
- 🔑 Credential Mismanagement – Prevent weak or mishandled access
- 📧 Phishing & Email Security – Spot and block deceptive emails
- 🎭 Social Engineering Defense – Recognize manipulation tactics
- 🛡️ Password & Identity Protection – Safeguard accounts and identities
- 📂 Secure Client Data Handling – Protect sensitive client information
- 📊 Analyst Operational Security Practices – Adopt secure workflows in daily operations

### Learning Approach
- 🎥 Short video‑based learning (Vivida Reels)  
- 🧩 Scenario‑based simulations  
- 📚 Real‑world case studies  
- 🔄 Continuous reinforcement

➡️ Custom modules were created to address these gaps.

## **Accessibility Testing**
Accessibility was prioritized to ensure training is usable by all.  

**Tools Used**  

- 🛠️ Fezzant Accessibility Scanner – Automated accessibility checks
- 🧩 axe DevTools – Browser‑based accessibility testing suite
- 🗣️ Microsoft Narrator – Screen reader for usability validation
- ⌨️ Manual Keyboard Navigation – Hands‑on accessibility verification

### Key Findings
- ⌨️ Partial keyboard navigation support
- 🌐 Missing HTML language attributes
- 🔍 Zoom disabled via viewport settings
- 🎬 Minor caption synchronization issues
- 🏷️ Elements lacking proper label 

---

## **Practical Challenges**
- Large video uploads (>100MB) slow or failed  
- No option to delete incorrect uploads  
- `.mov` format unsupported on Windows  
- Limited content management flexibility  

---

## **Accessibility Improvements Recommended**

- ⌨️ Enable full keyboard navigation
- 🌐 Add HTML language attributes
- 🔍 Allow zoom & text scaling
- 🎬 Improve caption synchronization
- 🎞️ Support multiple video formats or auto‑convert uploads
- 🗑️ Introduce content deletion functionalit

## **Program Rollout Plan**

1. Platform setup & content upload  
2. Employee onboarding  
3. Training delivery  
4. Engagement monitoring  
5. Feedback & continuous improvement
